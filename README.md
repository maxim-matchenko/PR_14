Описать структуру с именем «Дилерский центр», содержащую следующие поля: модель автомобиля; фирма; год выпуска; комплектация; цена.
Написать программу, выполняющую следующие действия:
- ввод с клавиатуры данных в массив, состоящий из n элементов типа Дилерский центр;
- вывод записей должны быть организован по возрастанию года выпуска;
- вывод на экран информации о конкретной модели автомобиля, введенной с клавиатуры;
- вывод информации о наиболее дорогом автомобиле.
